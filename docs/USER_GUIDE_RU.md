# Vertex Color Master — Руководство пользователя

## Что это

VCM — аддон для Blender для редактирования цветовых атрибутов вершин и
углов граней (per-vertex / per-corner color attributes) в режиме
**Vertex Paint**. Аддон добавляет неразрушающий рабочий процесс
«изоляции каналов», операции с каналами по маске, перенос данных
(vcol ↔ uv ↔ веса ↔ нормали) и набор удобных инструментов рисования
(градиент, рандомизация, постеризация, ремап).

Панель аддона находится во вкладке **VCM** боковой панели 3D-вьюпорта,
доступна в режиме Vertex Paint.

## Структура панели

Панель VCM сверху вниз:

1. **Заголовок состояния** — текущий режим (Normal / Isolated), имя
   активного атрибута, тип данных / домен, текущая маска каналов.
   Жёлтое предупреждение для атрибутов с доменом `POINT` и для
   «осиротевших» временных атрибутов `VCM-ISO_*`.
2. **Действия в режиме изоляции** — видны только в режиме Isolated:
   `Apply Changes` / `Discard Changes`.
3. **Brush Settings** — цвет / значение, режим смешивания, сила.
4. **Channel Mask** — переключатели R / G / B / A, текущая маска и
   кнопка `Isolate Active (X)` или `Isolate Mask: …`.
5. **Blur (selected channels)** — см. ниже.
6. **Data Transfer** (только Normal) — перенос данных между каналами.
7. **Misc Operations** — градиент, случайные острова и т.д.
8. **Cleanup** — появляется при наличии «осиротевших» `VCM-ISO_*`.
9. **Help / Misc** — `Docs (EN)`, `Docs (RU)`, `Logs Folder`,
   `Clear Log`.

## Базовый рабочий процесс

1. Сделайте меш активным и переключитесь в **Vertex Paint**.
2. Выберите активный цветовой атрибут в
   `Object Data Properties > Color Attributes`.
3. Нажмите **Isolate Active (R/G/B/A)** (или хоткей), чтобы войти в
   режим изоляции одного канала.
4. Раскрашивайте, заливайте или редактируйте временный изо-атрибут.
5. Нажмите **Apply Changes**, чтобы записать изменения обратно в
   исходный атрибут, или **Discard Changes**, чтобы сбросить правки.

## Изоляция одного канала (R / G / B / A)

При выборе одного канала в `Channel Mask` и нажатии **Isolate Active (X)**
(или `Alt+1/2/3/4`) создаётся временный атрибут с именем
`VCM-ISO_<R|G|B|A>_<original>`. Значение канала транслируется во все
каналы RGB, поэтому виден как градации серого — удобно красить от чёрного
к белому.

Apply копирует отредактированное значение обратно в нужный канал
исходного атрибута. Остальные каналы не трогаются.

## Многоканальная маска (RG, RGB, RGBA…)

Выберите два или более канала в `Channel Mask` и нажмите **Isolate Mask**.
VCM создаёт временный атрибут с именем `VCM-ISO_<MASK>_<original>`
(маска записана в порядке RGBA — `RG`, `RB`, `RGB`, `RGBA` и т.д.).

Выбранные каналы копируются как есть из исходного атрибута. Невыбранные
RGB-каналы во временном атрибуте обнуляются; невыбранная Alpha
устанавливается в 1.0. Кисть остаётся в обычном RGB-режиме, чтобы можно
было сразу красить нужным цветом.

Apply копирует обратно **только** каналы, входящие в маску. Каналы вне
маски в исходном атрибуте сохраняются без изменений. Discard удаляет
временный атрибут без какого-либо влияния на исходный.

## Временные атрибуты (VCM-ISO_*)

Атрибуты `VCM-ISO_*` — служебные буферы, создаваемые операцией Isolate.
Они никогда не считаются пользовательскими данными и должны исчезать
после Apply или Discard.

Если Blender аварийно завершился, файл был сохранён в режиме изоляции
или операция была прервана, временные атрибуты `VCM-ISO_*` могут
остаться на меше. Запустите **Cleanup VCM Temp Attributes** (кнопка в
панели или в настройках аддона), чтобы удалить все валидные `VCM-ISO_*`
на активном меше, не задевая остальное.

## Blur Selected Channels

Сглаживает выбранную маску каналов на активном цветовом атрибуте.
Воздействует на **весь** активный атрибут (без режима «только выделение»
в текущей версии).

Настройки (секция `Blur` панели):

- **Mode** — алгоритм:
  - **Smooth Vertex** (по умолчанию) — диффузия значений каналов по
    вершинам, связанным рёбрами. Сглаженное значение каждой вершины
    транслируется во все её петли (loops), благодаря чему скачки
    значений между углами одной и той же вершины «склеиваются» в одно
    непрерывное значение. Получается плавный градиент без видимых
    границ полигонов.
  - **Legacy Loop** — исходный алгоритм усреднения по соседним петлям.
    Быстрее, но оставляет заметные «клетки» вдоль граней; оставлен как
    запасной вариант.
- **Strength** (`0.0..1.0`, по умолчанию `0.5`) — коэффициент смешивания
  текущего значения и среднего по соседям за одну итерацию.
- **Iterations** (`1..20`, по умолчанию `1`) — количество итераций.

Поведение:

- На обычном цветовом атрибуте: размывает каналы, отмеченные сейчас в
  `Channel Mask`.
- На временном атрибуте `VCM-ISO_<MASK>_*`: размывает изо-маску.
  Одноканальные изо-временные атрибуты хранятся как градации серого
  (R==G==B), поэтому Blur выполняется по RGB, чтобы сохранить
  «трансляцию», — Apply всё равно копирует результат в нужный канал
  оригинала.
- Только домен `CORNER`. Для `POINT` операция отказывается выполняться
  с понятной ошибкой.
- Каналы вне маски сохраняются точно (бит-в-бит).
- Кисть с режимом Blur **пока не реализована** — запланирована на
  будущую экспериментальную итерацию.

## Pie Menu (V)

Pie Menu по умолчанию привязано к клавише **V** (настраивается).

**Normal mode** (направления L, R, B, T, TL, TR, BL, BR):
- L / R / B / T: Isolate G / B / A / R.
- TL: `Isolate Mask: <текущая маска>`.
- TR: `Select / Restore RGBA`.
- BL: `Blur Selected Channels`.
- BR: `Cleanup VCM Temps`.

**Isolated mode**:
- L: `Discard Changes`. R: `Apply Changes`. B: `Blur Selected Channels`.
- T: статус (имя оригинального атрибута + изо-маска).
- TL: `Select / Restore RGBA`. BR: `Cleanup VCM Temps`.

## Умное переключение изоляции (Channel Roll)

VCM отслеживает состояние активного `VCM-ISO_*`: **clean** (совпадает с
тем, что было записано при создании изоляции) или **dirty** (изменён —
кистью, заливкой или любой другой операцией, не только VCM). Все точки
входа в изоляцию работают по одним правилам:

- **Normal mode** — обычная изоляция.
- **Clean isolate, другая цель** — VCM автоматически отбрасывает
  текущий временный атрибут и открывает запрошенный. Без подтверждения,
  без предупреждения.
- **Clean isolate, та же цель** — no-op (`Already isolated on R` и т.п.).
- **Dirty isolate, другая цель** — переключение блокируется. В
  заголовке панели появляется `Isolated: Unsaved Changes`, и
  выводится предупреждение: `Current isolated channel has unsaved
  changes. Apply or Discard before switching.`
- **Unknown state** (метаданные потеряны при перезагрузке, меш изменён
  извне и т.п.) — также блокируется. Сначала Apply или Discard.

Определение dirty работает на уровне меша и не зависит от способа
правки — берётся «отпечаток» (fingerprint) выбранных каналов
изо-маски при создании и сравнивается при каждой попытке
переключения. Мазки кистью Vertex Paint детектируются так же надёжно,
как и операции VCM.

Эта же логика применяется к:

- `Alt+1..4` — Isolate R/G/B/A.
- `Alt+5` (Select / Restore RGBA) — выходит из изоляции при clean,
  блокирует при dirty.
- `Alt+W` (Roll Isolate Next) — R → G → B → A → R.
- `Alt+S` (Roll Isolate Previous) — R → A → B → G → R.
- Кнопка `Isolate Mask: …` — переключает на выбранную в панели
  многоканальную маску.

Roll-хоткеи работают и в normal mode: нажатие `Alt+W` без активной
изоляции открывает R; `Alt+S` — A. Из одноканальной изоляции делают
один шаг по последовательности. Из многоканальной (например, `RG`)
стартуют с края (`R` для Next, `A` для Previous).

**Отдельного режима Quick Preview нет.** Единственный рабочий
процесс — Editable Isolate, просто теперь он умнее переключается, если
временный атрибут не редактировался.

### Подсказки в панели

В режиме изоляции в заголовке состояния отображается одно из:

- `Isolated: Clean (auto-switch enabled)` — зелёная галочка.
- `Isolated: Unsaved Changes — Apply or Discard before switching`.
- `Isolated: Unknown state — Apply or Discard before switching`.

Кнопки `< Prev` / `Next >` (channel roll) находятся под Apply / Discard.
В состоянии dirty / unknown они становятся неактивными.

## HUD-уведомления

VCM рисует короткие статусные сообщения внутри 3D-вьюпорта, привязанные
к низу — над строкой состояния, чтобы они никогда не оказывались за
верхней панелью или toolbar. Новые сообщения добавляются сверху стопки;
старые гаснут плавно, и оставшиеся «съезжают» вниз. Реализация
повторяет паттерн MACHIN3 (отдельный модальный оператор на каждое
сообщение).

Триггеры:

- Isolate / Mask isolate — `Isolate R`, `Isolate Mask: RG` или
  `Switched to G`, `Switched to Mask: RGB` при умном переключении из
  чистой изоляции.
- Dirty-блок — `Unsaved isolate changes. Apply or Discard first.`
- Apply / Discard — `Applied R`, `Applied Mask: RG`, `Discarded isolate`.
- Restore RGBA — `Restored RGBA` (или `Channel mask: RGBA` из normal).
- Channel roll — `Roll: G`, `Roll: B`.
- Blur — `Blurred Mask: RG`.
- Cleanup — `Cleaned 3 temp attribute(s)` или `No VCM-ISO temp
  attributes`.
- Отказ POINT-домена — `POINT domain not supported for this operation`.

Цвета: белый (info), зелёный (success), янтарный (warning).

**Канальные акценты (Итерация 8)** — обычные сообщения isolate /
switch / roll / apply / discard окрашиваются под канал или маску:

- `R` — красный, `G` — зелёный, `B` — синий, `A` — лавандовый.
- Многоканальные маски (`RG / RGB / RGBA / …`) — мягкий cyan.

`WARNING` (dirty-блок, отказ) и `ERROR` всегда рисуются в цвете уровня
независимо от канала — имя канала включается в текст dirty-блока,
например: `Unsaved A changes. Apply or Discard first.`

Переключатели в `Edit → Preferences → Add-ons → Vertex Color Master`:

- **Show HUD Notifications** (по умолчанию ON)
- **HUD Duration** в секундах (0.4 – 6.0, по умолчанию 1.5)
- **HUD Scale** множитель размера текста (0.5 – 2.5, по умолчанию 1.0)

Отключение HUD не отключает операторы — обычные сообщения в
Info-строке Blender и записи `vcm_debug.log` пишутся всегда.

## Хоткеи

Все хоткеи привязаны к keymap **Vertex Paint** и не срабатывают в
других режимах.

| Действие                          | Клавиша | Модификаторы |
|-----------------------------------|---------|--------------|
| Pie Menu                          | V       | —            |
| Flip Brush Colors                 | X       | —            |
| Isolate R                         | 1       | Alt          |
| Isolate G                         | 2       | Alt          |
| Isolate B                         | 3       | Alt          |
| Isolate A                         | 4       | Alt          |
| Select / Restore RGBA             | 5       | Alt          |
| Apply Isolated                    | E       | Alt          |
| Discard Isolated                  | Q       | Alt          |
| Cleanup VCM Temp Attributes       | C (off) | Alt          |
| Roll Isolate Next                 | W       | Alt          |
| Roll Isolate Previous             | S       | Alt          |

Изменить или отключить любой хоткей можно через
`Edit > Preferences > Add-ons > Vertex Color Master > Hotkeys`.

В каждой строке доступно:

- галочка **Enable**;
- название действия;
- текущая привязка в человекочитаемом виде (`Alt + 1`,
  `Ctrl + Shift + B`);
- кнопка **Rebind** — нажмите, затем введите комбинацию клавиш одним
  нажатием. **Esc** отменяет. Чистые модификаторы (Ctrl / Shift / Alt /
  Cmd сами по себе) игнорируются.
- кнопка **Reset** (иконка стрелки) — сбрасывает только эту строку к
  значению по умолчанию.

В шапке секции есть **Reset to Defaults**, сбрасывающая все хоткеи
сразу. Расширенные настройки (значение, повтор, отпускание клавиши и
т.п.) доступны через стандартный
`Preferences > Keymap > Vertex Paint`.

## Логи

Диагностический файл: `<addon>/logs/vcm_debug.log`.

Лог автоматически ротируется при ~2 МБ; хранится до 3 нумерованных
резервов (`vcm_debug.log.1`, `.2`, `.3`). Активный файл — всегда
`vcm_debug.log`.

В настройках аддона:

- **Debug Mode** — переключатель: при ON в файл пишется DEBUG-уровень.
- **Open Logs Folder** — открывает папку в системном файловом менеджере.
- **Clear Log File** — очищает активный лог; ротированные резервы
  не трогаются.
- **Copy Diagnostics Summary** — копирует в буфер обмена компактный
  текстовый отчёт (версия аддона / Blender, активный объект /
  атрибут / домен, маска каналов, состояние изоляции + dirty,
  таблица хоткеев, список POINT-операций, последние 20 строк лога).
- **Save Diagnostics Summary** — сохраняет тот же отчёт в файл
  `vcm_diagnostics_*.txt` рядом с логом.

Те же кнопки `Logs Folder`, `Clear Log` и `Copy Diagnostics` доступны
и в секции `Help / Misc` панели.

Записи уровней `WARNING`, `ERROR`, `EXCEPTION` пишутся всегда, вне
зависимости от Debug Mode.

## Geometry Mask Generator

Топологический генератор масок вогнутости / выпуклости. **Не** AO —
без лучей, без сэмплирования света и без информации о сцене. Детекция
по знаковому диэдральному углу; распространение BFS по смежности
вершин.

### Рабочий процесс (только в Isolate)

1. Выберите Channel Mask в панели (R / G / B / A / RG / RGB / RGBA).
2. Нажмите **Isolate** (или `Alt+1..4` для одного канала).
3. Используйте **Generate Concavity** или **Generate Convexity**
   в секции Geometry Masks.
4. **Apply** — записать результат в исходный атрибут;
   **Discard** — откатить.

Генератор пишет во все каналы текущей iso-маски. Примеры:

- Isolate R → значение идёт в R.
- Isolate G → значение идёт в G.
- Isolate RG → значение broadcast на R и G.
- Isolate RGB → broadcast на R, G и B.

Concavity и Convexity — отдельные эффекты с отдельными настройками и
отдельными кнопками **Generate**. Нет "Generate Both" и нет пресетов.

### Параметры на эффект

Одинаковый набор для Concavity и Convexity:

- **Strength** — итоговый множитель интенсивности (`0..1`).
- **Width** — дистанция распространения в кольцах смежных вершин.
  `0` = только концы найденных рёбер.
- **Angle Threshold** — рёбра, чей диэдральный угол отклоняется от
  плоского меньше чем на это число градусов, не дают вклада.
- **Falloff** — Linear / Smooth (smoothstep) / Sharp (квадратичный).
- **Blend Mode** — Replace / Add / Max. По умолчанию **Max** —
  сохраняет более яркие существующие данные.
- **Smooth After Generate** + **Smooth Iterations** — опциональное
  vertex-diffusion сглаживание по каналам iso-маски.

### Normal mode

В секции Geometry Masks показывается только:

> Available in Isolate mode.
> Select Channel Mask above and click Isolate.

Прямой генерации в обычный атрибут нет. Это держит процесс
неразрушающим и форсирует Apply / Discard как явную точку фиксации.

### Поддержка домена

- `CORNER` — поддерживается.
- `POINT` — отказ с понятной ошибкой ("Geometry Mask Generator
  currently supports CORNER domain only.") — данные не меняются.

### Обработка краевых случаев

Non-manifold и граничные рёбра пропускаются (счётчик в
`vcm_debug.log`); n-gons / треугольники / разрозненные острова
обрабатываются bmesh нативно. Генератор не падает на плохой топологии.

## Текущие ограничения

- **Blur Brush** (кистевой Blur) ещё не реализован (запланирован).
- **Поддержка POINT-домена** ограничена; см. ниже.
- **Hold-Alt модальный ролл** (зажать `Alt+1`, затем нажать `2` без
  отпускания Alt, чтобы циклически переключать каналы одной серией)
  в текущей итерации не реализован. Настраиваемые `Alt+W` / `Alt+S`
  закрывают тот же сценарий.

## Поддержка POINT-домена (ограниченная)

VCM ориентирован на CORNER. Большинство loop-индексированных операций
требуют атрибут на `CORNER` и отказываются работать на `POINT`, чтобы
не повредить данные. С Итерации 8 ограниченный набор простых
поэлементных операций работает на обоих доменах:

**Поддерживается на `POINT` и `CORNER`:**

- Fill
- Quick Fill (Fill With Color)
- Invert
- Remap
- Posterize

Уважают текущую маску каналов (`R / G / B / A / RG / RGB / RGBA / …`)
и оставляют невыбранные каналы без изменений. Работают с
`BYTE_COLOR` и `FLOAT_COLOR` в обоих доменах. Маски выделения
(face / vertex paint mask) поддерживаются.

**По-прежнему только CORNER (отказ на POINT с понятной ошибкой + HUD):**

- Blur Selected Channels
- Gradient
- Randomize Mesh Island Colors / Per Channel
- UVs ↔ Color, Normals ↔ Color, Weights ↔ Color
- Blur Brush (запланирован)

Чтобы использовать неподдержанные операции на `POINT`-атрибуте,
переведите его в **Face Corner** через
`Object Data Properties > Color Attributes > arrow menu > Convert Domain`.

## Устранение неполадок

### Дубликаты установки аддона

Если аддон включён одновременно как `bl_ext.user_default.vertex_color_master`
(через систему расширений) и как `vertex_color_master` (`scripts/addons`),
живым реально является только один Python-модуль. Отключите дубль через
`Edit > Preferences > Add-ons` и перезапустите Blender для чистого
состояния.

### Осиротевшие атрибуты VCM-ISO_*

Запустите **Cleanup VCM Temp Attributes**. Удаляются только атрибуты,
имя которых строго совпадает с шаблоном `VCM-ISO_<MASK>_<name>`.

### Канал Alpha выглядит полностью белым

Это ожидаемо. Атрибуты `BYTE_COLOR/CORNER` по умолчанию имеют alpha=1.0,
что отображается как белый, когда Alpha — изолированный канал.

### Сообщить о баге

1. Включите Debug Mode в настройках аддона.
2. Нажмите **Clear Log File**.
3. Воспроизведите проблему.
4. Нажмите **Open Logs Folder** и приложите `vcm_debug.log`.
5. Укажите версию Blender и точные шаги воспроизведения.

## Обновления

VCM содержит встроенный апдейтер. Работает **только по ручной проверке** —
никаких фоновых опросов и телеметрии. Откройте
`Edit > Preferences > Add-ons > Vertex Color Master` и используйте блок
**Updates** в верхней части настроек аддона.

Кнопки:

* **Check for Updates** — опрашивает
  `github.com/pressfk/vertex_color_master/releases` и сообщает, доступен
  ли более новый билд.
* **Install Update** — скачивает ZIP релиза, делает резервную копию
  текущей установки в `<addon>/backup/` и заменяет файлы аддона.
  Перезапустите Blender, чтобы загрузить новый код.
* **Restore Backup** — откат к предыдущей версии из резервной копии,
  созданной последним обновлением.
* **Open Releases Page** — открывает страницу релизов GitHub в браузере
  (также используется как ручной fallback, если обновление не прошло).

Если GitHub-репозиторий или релиз ещё не опубликованы, проверка вернёт
ошибку — это ожидаемое поведение в период выкатки.
